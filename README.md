# Жолсерік — доставка Шымкент → Ташкент

**Трек:** Проблемная зона 1 — The Landlocked Advantage (Global TradeTech & Smart Logistics)

**Одна боль:** продавец с рынка Шымкента заранее не знает полную стоимость, сроки и документы для отправки товара в Ташкент.

**Решение:** сайт, где продавец пишет обычным текстом, что везёт, и сразу видит цену, срок и документы. Одной кнопкой отправляет заявку перевозчику.

## Стек
- Python, Streamlit (сайт)
- Gemini API (ИИ понимает текст продавца)
- JSON-файлы с данными от перевозчиков

## Архитектура
- `app.py` — страница сайта: вкладки «Продавцу» и «Перевозчику»
- `ai.py` — ИИ: текст продавца → данные (JSON). Цены ИИ не считает
- `calc.py` — расчёт цены и срока по таблице `data/prices.json`
- `storage.py` — сохранение заявок для перевозчика
- `data/` — цены, сроки и документы от перевозчиков

## Как запустить локально
1. Установить Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопировать `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml` и вставить свой ключ Gemini API.
4. `streamlit run app.py` — сайт откроется в браузере.
