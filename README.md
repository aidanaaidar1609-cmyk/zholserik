# 🚚 Жолсерік AI — Intellectual Cross-Border Logistics Hub

**Zholserik AI** — интеллектуалды логистикалық хаб (Шымкент 🇰🇿 ➔ 🇺🇿 Ташкент коридоры). Платформа оптимизирует трансграничную торговлю, помогая продавцам моментально рассчитывать логистику, документы и отправлять заявки перевозчикам.

---

### 📌 Трек
**Кейс 1: The Landlocked Advantage (Global TradeTech & Smart Logistics)**

### 💡 Проблема
Продавцы и малый бизнес в Шымкенте перед отправкой груза в Узбекистан (Ташкент) не знают точную итоговую стоимость, реальные сроки доставки, а также список необходимых таможенных документов и разрешений.

### 🚀 Решение
Интерактивный веб-сервис с поддержкой 3 языков (KZ, UZ, RU) и ИИ-обработчиком:
1. **AI-Парсер (Gemini API):** Продавец описывает груз обычным языком (например, *"500 кг бытовой техники в Ташкент"*), а ИИ автоматически распознает категорию и вес.
2. **Интеллектуальный калькулятор:** Автоматический расчет стоимости на основе реальных оптовых тарифов (модель от 3 тонн) и прогнозирование сроков.
3. **Таможенный ассистент:** Проверка таможенного статуса и выдача полного пакета сопроводительных документов (CMR, Инвойс, СТ-1 и др.).
4. **B2B-панель перевозчика:** Безопасный доступ для аккредитованных водителей и логистов для принятия заявок в работу.

### 🛠️ Технический стек
* **Frontend / UI:** Python, Streamlit (Custom Indigo Theme)
* **AI & NLP:** Gemini API (модель parsing & structured output)
* **Backend logic:** Python, Pandas
* **Deployment:** Streamlit Cloud, GitHub

---

### 📁 Архитектура проекта
* `app.py` — главный веб-интерфейс (вкладки «Продавцу», «Перевозчику», переключение языков KZ/UZ/RU).
* `ai.py` — ИИ-модуль распознавания текста продавца (преобразование в JSON без расчета цен).
* `calc.py` — алгоритм расчета стоимости, сроков и формирования пакета таможенных документов.
* `storage.py` — хранение и обработка заявок для B2B-панели перевозчиков.
* `data/` — структурированные тарифы, нормы таможенного контроля и документы.
* `my_banner.png` — брендированный футуристичный баннер платформы.

### 🚀 Как запустить локально
1. Клонировать репозиторий: `git clone https://github.com/aidanaaidar1609-cmyk/zholserik.git`
2. Установить зависимости: `pip install -r requirements.txt`
3. Создать файл `.streamlit/secrets.toml` и добавить: `GEMINI_API_KEY = "your_key"`
4. Запустить проект: `streamlit run app.py`
